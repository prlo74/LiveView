What the signals mean

Agent Web draws what each agent is doing right now. With several agents running it shows the web, with one it shows the core. Colours mean the same thing everywhere.

Reactive effects

What the core does for each thing the agent does, running live. The web view uses the same colours.

Colours

Green · EditWriting or changing a file. Also tests passing and finished steps.
Cyan · ReadOpening a file. Cyan is also the default for an agent that is working.
Yellow · Search and goalSearching the code. The goal headline and goal marker are yellow too.
Amber · RunRunning a command or the tests.
Blue · WebBrowsing or fetching a web page.
Purple · HelperHanding work to a helper agent.
Red · ErrorA tool call failed or was denied, or tests failed.

Web view: several agents

HexagonOne agent. The main agent is the big one in the middle; helpers sit round it, their own helpers further out. It glows while working.
Coloured outer ringWhich tools the agent has used, in proportion.
Dashed spinning ringSpins faster the more actions it took in the last 30 seconds.
Strings of codeEach line to the parent is made of the code the helper is looking at, scrolling toward the parent. Dim when idle.
Flash along a stringAn update sent to the parent, in the colour of what happened. Purple “New helper” travels out; green “Done” travels back.
Strip of cellsIts last 12 actions, newest on the right. A blinking cell is still running.
BannerTests passed or failed, the agent finished, or an error. Shows for a few seconds.

Core view: one agent

SphereThe agent. Neurons are linked to their nearest neighbours; the sphere breathes while it works.
Chain of neurons firingEvery action fires a chain from the centre toward the current step, in the action’s colour. A white dot marks its head. A running command keeps firing until it ends.
FlickerBackground neurons blink more as the agent gets busier.
Tick ringsTurn faster the more actions in the last 30 seconds.

Plan and goal

GoalThe first sentence of the agent’s task, shown top left with a progress bar. The marker at the end of the orbit turns green when every step is done, and the whole network flares.
Orbit of stepsThe steps from the agent’s to-do list. Green up to the current step, pulsing on the current one, dim dashes for what is next.
Green hex on a stepThat step is done. Sparks fly when it is ticked off.
No plan writtenWhen the agent never writes a to-do list, the bar and orbit show its last actions instead, ending in “Next action”.

Alerts

Needs youThe agent is waiting for you to approve something in Claude. Shown once it has waited 30 seconds, until that tool call ends; asks that auto mode answers for you are left out. The window title shows how many are waiting.
StuckIts last 3 actions failed, or the same action failed 3 times in a row.
StrugglingAt least 5 of its last 10 actions failed.
QuietMarked working but no action for over 3 minutes. It may be thinking on a long answer.
FireworksThe project is done: the main agent ticked off its whole plan, or every helper finished and the main agent stopped. Once per project.

Styles and screensaver

StylesPick one from the Style menu in the header: from plain and high-contrast looks for daytime work to calm, slowly moving scenes that double as a screensaver. A style changes the look only: colours keep their meaning, and every alert works the same. Your choice is remembered.
ScreensaverAfter 10 minutes without mouse or keyboard, or press Z. The panels hide, the background keeps slowly morphing, the agents stay faintly visible, and a line at the bottom says what is going on. Any key or mouse move brings everything back.
Orange waveAn agent has been waiting for your approval and nothing has changed for over a minute: the screen edges glow orange, slow waves roll out from the centre, and a note says who is waiting. It shows over the screensaver too. Answer in the Claude app.

Panels

Details sidebarGoal, task, plan, stats, activity in the last minute, the code it is working in, and its history. Tab or the edge tab shows and hides it.
Task cardIn the web view, click an agent for its goal, plan and what it is doing now.
ActivityEvery update from every agent, newest first. Drag its bar to move it; expand it to see more.
Site previewThe site being built. A plain HTML site is read from its files and reloads after each edit; a site with a dev server shows that server. Drag to move, drag the corner to resize.
Servers already runningDev servers started on this Mac (by an agent or by you) are found every few seconds. Pick one from the menu in the preview, or leave it on Auto.
ReplayScrub back through everything since this window opened, or play it back at 1×, 4× or 16×. Back to live returns to now.
Power savingDraws fewer frames and drops the glow when the window is in the background or the Mac is on battery.
